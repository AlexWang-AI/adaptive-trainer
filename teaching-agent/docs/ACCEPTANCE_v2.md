## 三、新增「外部提速层」——104 条

按用户要求，收入教材没讲、但数一冲 140 分必须会的内容，每条含：

| 字段 | 含义 |
|---|---|
| `type` | 秒杀技巧 / 特殊结论 / 常见陷阱 |
| `when` | 什么题型用 |
| `how` | 怎么用（含公式） |
| `risk` | 什么情况下翻车 |
| `source` | **固定为 external**，与教材内容严格分离 |

样例（第 9 讲）：

```
[秒杀技巧] 表格积分法
  何时：多项式×指数/对数/反三角积分
  怎么：左列求导到零，右列连续积分，斜向相乘添符号 + − + −
        ∫x²e²ˣdx = ½x²e²ˣ − ½xe²ˣ + ¼e²ˣ + C
  风险：多项式次数高或对数型要先换元，否则符号错
```

其余如：泰勒展开阶数速判、AC−B² 极值快判、轮换对称性秒杀、收敛半径三秒判、
斜渐近线双极限速算、反函数二阶导公式、先二后一截面法等。
