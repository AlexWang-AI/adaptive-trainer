## 1. 升级项 A：颗粒化（L1→L2→L3→L4）

### 1.1 新层级定义

| 层 | 含义 | 例子（洛必达） |
|---|---|---|
| L1 | 教材导图分支 | 计算（求极限的方法） |
| L2 | 知识点 | 洛必达法则 |
| L3 | 要点（条件/易错） | 适用条件：0/0 或 ∞/∞ |
| **L4（新）** | **题型 + 解法步骤** | ① 验证未定式类型 ② 分子分母分别求导 ③ 再代值；循环型改用等价无穷小 |

### 1.2 枚举型知识点必须穷举

规则：**凡是教材出现「七种 / 三类 / 四个」这类数量词，就必须把每一个都列出来，并用原文 evidence 校验**。

已发现的缺口（第 1 讲）：

| 知识点 | 现在 | 应改为（教材原文） |
|---|---|---|
| 七种未定式 | 只列 0/0、∞/∞、0·∞ | 0/0、∞/∞、0·∞、∞-∞、0⁰、1^∞、∞⁰ **七种全列，每种给处理思路** |

教材佐证（`chunk_001_098.fixed.md`）：
- 2367 行「2 七种未定式的计算」
- 2563 行「0·∞ 型：主要思路 0·∞ 把 ∞ 放在分母，设置分母有原则，简单因式才下放」
- 2627 行「∞-∞ 型：一般有两种思路」
- 2697 行「∞⁰ 和 0⁰ 型：用恒等变形（取对数）」
- 2709 行「1^∞ 型：用好公式 lim u^v = e^{lim(u-1)v}」

**校验机制**：抽取完成后跑一个「枚举完整性检查」——模型给出 N 个，若原文出现「N 种/N 类」且数量不符 → 判定不合格，重抽。

### 1.3 L4 的生成方式

对每个 L2，取教材里以它为主体的例题（例 X.Y），抽出「解题步骤链」，压缩成 3–5 条 L4。**步骤必须来自教材解答，不许模型自创**。

## 2. 升级项 B：难度分层（数一 → 数二 / 数三）

### 2.1 数据结构

```json
{
  "name": "斯托克斯公式",
  "versions": ["y1"],          // 只在数一考
  "version_note": "数二数三不考曲线曲面积分"
}
```

### 2.2 三套版本的关系

| 版本 | 关系 | 处理 |
|---|---|---|
| **数一（基线）** | 全集 | 先做，最细 |
| 数二 | 数一 **删去** 曲线曲面积分、级数、无穷级数等 | 按教材「仅数学一」标注删 |
| 数三 | 数二 **再删** 物理应用，**加** 经济应用、无穷级数（部分） | 按标注增删 |

教材里的「(仅数学一、数学二)」「(仅数学三)」这类标注就是**权威的增删依据**，直接解析这些括号即可自动分层。

### 2.3 产物

```
textbook/tree/y1/  (基线，含全量 L4)
textbook/tree/y2/  (由 y1 自动裁剪 + 人工复核)
textbook/tree/y3/  (由 y2 增删 + 人工复核)
```

## 3. 升级项 C：第 2–10 讲按教材结构重建

### 3.1 问题

现在第 2–10 讲的 L1 是用「正文小标题」推导的，不是教材自己的「基础知识结构」导图，所以有偏差（例如第 8 讲「原函数」整块证据全丢）。

### 3.2 做法

1. 教材每讲开头都有一页「基础知识结构」**图片**（MinerU 输出为 base64 图片）。
2. 把这些页面图单独抽出来（不丢弃），走一条 **图片 → 分支结构** 的识别流程：
   - 优先：多模态模型直接读图输出分支树
   - 兜底：OCR + 人工校对（一讲约 25 个节点，校对成本可接受）
3. 用识别出的分支替换现在的 L1，重跑 L2/L3/L4 抽取。

### 3.3 验收

每讲 L1 分支数应与教材导图一致（一般 4–6 个），且分支名逐字来自导图。

## 4. 升级项 C+：题目知识架构（做题知识架构）

### 4.1 为什么需要

教辅题目难度高，**题目里蕴含的知识点在正文里可能没讲**。只靠正文抽树会漏。

### 4.2 流程

```
每道例题/习题
  └─ 逐步解答（LLM 按教材答案逐步展开，禁止跳步）
       └─ 每一步问：这一步在考什么？（考点标签）
            └─ 对齐主树：这个考点在 L2/L3/L4 里有没有？
                 ├─ 有 → 记一条 usage（题目 id ↔ kp id），并给该 kp 打「考过」标记
                 └─ 没有 → 生成候选知识点，进 review 队列
                      └─ 人工/二次校验通过 → 补进主树（标注来源：题目补充）
```

### 4.3 产物

```
textbook/tree/problem_graph.json
{
  "problem_id": "例1.22",
  "steps": [{"step": 1, "text": "...", "tests": ["kp:lim.taylor", "kp:app.lagrange"]}],
  "new_kps": ["候选知识点"],
  "coverage_gap": false
}
textbook/tree/coverage_report.json   # 主树 vs 题目 的差集与补齐结果
```

### 4.4 验收

- 每道题至少标注 1 个考点；
- 主树中「只被题目考到、正文没讲」的知识点全部补齐；
- 覆盖率报告显示：题目涉及的考点 100% 能在主树里找到（补完后）。

## 6. 验收标准（可量化）

| 指标 | 目标 |
|---|---|
| 枚举完整性 | 教材中「N 种/N 类」的知识点，列表数量与原文一致（100%） |
| L4 覆盖 | 每个 L2 至少 3 条 L4 步骤 |
| 难度标注 | 每个 L2 有 `versions` 字段，且与教材「(仅数一)」等标注一致 |
| 题目考点覆盖 | 补完后，题目涉及考点 100% 在主树中 |
| 证据可验 | 每条 L2/L3 的 evidence 能在原文逐字命中（≥95%） |
| 可视化 | 每讲一张 PNG，L1/L2/L3/L4 四层可读 |

## 7. 风险

| 风险 | 应对 |
|---|---|
| 导图页是图片，识别不准 | 双路（多模态 + OCR）交叉，人工只校 5 个/讲 |
| 题目拆解过度发散 | 限定「每一步只标 1–2 个考点」，且必须能对上教材解法 |
| 补进主树的知识点质量参差 | 全部标 `source: problem`，可一键回滚 |
| 数二/数三裁剪误删 | 裁剪规则只依据教材显式标注，不做推断 |
