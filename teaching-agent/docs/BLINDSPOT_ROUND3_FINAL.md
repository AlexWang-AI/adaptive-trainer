### 2. 区间再现公式（提速层 · 讲9）

```
∫₀ᵃf(x)dx = ∫₀ᵃf(a−x)dx
常配 ∫₀^π x·f(sin x)dx = (π/2)∫₀^π f(sin x)dx 直接消掉 x
风险：区间不对称时不能套；换元后上下限要同步对调
```

### 3. Γ 函数（提速层 · 讲8/9）

```
∫₀^∞ x^{s−1}e^{−x}dx = Γ(s)；Γ(n+1)=n!
∫₀^∞xⁿe^{−ax}dx = n!/a^{n+1}；∫₀^∞e^{−x²}dx = √π/2
风险：Γ(s) 要求 s>0；指数不是 −x 时先换元
```
