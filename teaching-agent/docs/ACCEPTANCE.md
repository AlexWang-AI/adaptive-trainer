## 三、三层质控机制

### 第一层：抽取时（build_tree_v2.py）
- 证据必须**逐字命中原文**（归一化后）
- 证据必须**与节点名相关**（含 2 字关键词）
- 不相关时先按节点名在原文搜替代句，**搜不到才丢**

### 第二层：红队（critic_tree.py + apply_critique.py）
- 拿树与原文对撞，只挑三类：`missing` / `wrong` / `incomplete`
- `missing`、`incomplete` 证据命中即自动补入（累计 **406 条**）
- `wrong` **一律人工裁决**（红队 3 次全误判，见 `CRITIC_ADJUDICATION.md`）

### 第三层：验收（coverage_check.py）
- 用教材自身的例题清单当尺子
- 有限集合比对，可 100%，与模型判断无关

## 七、复跑方式

```bash
python tools/build_tree_v2.py --lecture N --file <原文切片>   # 建树
python tools/critic_tree.py --lecture N                      # 红队
python tools/apply_critique.py --lecture N                   # 补入（证据校验）
python tools/extract_examples.py --lecture N                 # 抽例题
python tools/map_examples.py --lecture N                     # 题→知识点
python tools/coverage_check.py                               # 验收
python tools/render_overview.py                              # 出图
```
