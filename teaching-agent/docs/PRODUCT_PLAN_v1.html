你的诉求状态怎么做的

一句话产品判断：你现在做的不是「AI 讲题工具」，而是「可验收的自主学习闭环」。 闭环 = 诊断 → 规划 → 讲 → 练 → 改 → 验收。现在讲、练、改都有雏形，缺的是「诊断」和「验收」的量化，以及「改」之后的复盘回流。

二、当前体验的五个断点（按杀伤力排序）

#断点用户感受根因
1错题只记了「错」，没记「为什么错」下次遇到同类题还是错，感觉系统没变聪明错题本只存题目+诊断，没有回流到出题策略
2看不到「我到底在进步吗」每天刷，但不知道离 90 分还有多远只有知识点勾选，没有分数曲线、没有剩余轮次估算
3通关即结束，没有复习一周后全忘，前面的勾变成假象没有间隔复习与遗忘曲线
4题只有 3 道，练不够刚有点感觉就没了题卡是一次生成的，没有「再来一组」与变式
5侧问虽好，但要主动点卡住时不会想到去问缺少「检测到你停了 30 秒」这类被动触发

三、三轮迭代

每一轮都以「可验证的提分证据」收口，而不是堆功能。

第 1 轮（1 周内）：让「改」形成回流 现在就能做

  • 错题重练队列：错题按 1 天 / 3 天 / 7 天 三次回流；答对两次才算真正消掉（写 mastery 时才允许打勾）。
  • 诊断结果反向影响出题：把 misconception 作为下一轮题卡的硬约束（「这轮必须出一道专门考这个误解的干扰项」）。
  • 每轮结束给一张「本轮账本」：讲了几层 / 做了几题 / 错在哪 / 断了哪一步 / 下次复习时间。
  • 再练一组：同一知识点一键续 3 道（复用 lesson 节点，只出题不重讲，约 4 s）。

第 2 轮（2~4 周）：让「进步」可量化 需要你确认数据口径

  • 掌握度模型：知识点维度 = f(答对率, 难度加权, 最近一次时间)；用 Laplace 平滑，避免「做 1 题=100%」。
  • 能力雷达：按考纲六大块（极限/微分/积分/多元/级数/微分方程）算掌握度，侧栏可视化。
  • 提分曲线：以「首次诊断分 → 当前能力分」为纵轴，每轮记录一次；同时给「到 90 分预计还需 X 轮 / Y 小时」的 区间（P50/P80），不给假精确。
  • 考点热力图：69 个知识点按考频×掌握度上色，一眼看出「高频没掌握」的红区。

第 3 轮（1~2 月）：从「练会」到「考得出」 后面再说

  • 模考模式：25 分钟一组真题，逐步撤掉脚手架（提示、解析先不给），测真实迁移。
  • 错因归类统计：「概念 60% / 方法 30% / 粗心 10%」——粗心类不再占错题本，避免噪声。
  • 教师/家长视图：只看热力图与本周变化，不看成篇对话。
  • 多科扩展：curriculum 换一份数据即可，架构不动。

四、提分过程怎么「可视化」（核心设计）

不做花哨图表，只回答学生最关心的三个问题。
学生的问题界面上给什么数据来源
我哪里有问题？考点热力图 + 薄弱点前三（带考频标签）student_kp 掌握度 × curriculum 考频
我还要多久？「预计还需 3~5 轮，约 1.5 小时」+ 进度条历史每轮提分速率 + 剩余知识点数
我现在什么水平？能力分（0-100，区间）+ 六大块雷达每轮题卡的难度加权正确率
设计原则：所有数字都必须可解释。学生点任意一个分数，都能展开看到「哪几道题、哪几次作答、怎么算出来的」。做不到可解释，就不要显示。

五、为什么这样设计（几个关键取舍）

✔ 旁路而不是并进主图

侧问、诊断都不进主状态机。理由：主链路是「讲课→出题→判题」，多一个节点就多一份延迟和上下文污染，而这两个功能恰恰要求「独立上下文」。

✔ 自动推进而不是弹窗

用户要的是「丝滑」，不是「掌控每一步」。倒计时可取消，既减少点击又不剥夺控制感。

✘ 不做「多智能体群聊」

Cognition / Anthropic 的实证都指向同一结论：多 agent 只在「读并行」时有效，写操作必须单线程。教学是强依赖场景，群聊只会让上下文互相污染。

✘ 不做自适应出题的「完全体」

IRT/CDM 需要上千条作答数据，冷启动阶段用「考频 × 掌握度」的启发式更诚实，也更好解释。

六、需要你拍板的五件事

这五个决定会改变后面 2~4 周的工作量，建议逐条回我。
1. 掌握度的口径：按「知识点」算（69 个，细但稀疏），还是按「章节」算（10 个大块，粗但稳）？我的建议：先按章节给雷达，知识点只做热力图。
2. 提分基准从哪来：要不要在第 1 轮先做一次「诊断卷」（20 题，约 15 分钟）作为起点分？没有起点分，后面的曲线没有意义。
3. 复习节奏：错题回流用 1/3/7 天，还是按「隔一次就复习」？前者更科学，后者更无感。
4. 模考模式要不要现在做：它能显著提升「考得出」的可信度，但要额外设计计时、跳题、交卷、批改，约 1 周。
5. 数据边界：诊断会存学生原话（可能包含个人信息）。只存本机 sqlite、不上传，还是允许匿名汇聚做错因统计？
